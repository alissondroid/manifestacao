# Código de Conduta

Adotamos o [Contributor Covenant v2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Este projeto é político por tema, mas as discussões aqui são técnicas: não toleramos assédio, discurso de ódio, ataques pessoais nem propaganda eleitoral nas issues e PRs.

Denúncias: abra um contato privado com a mantenedora pelo perfil do GitHub (@alissondroid).
